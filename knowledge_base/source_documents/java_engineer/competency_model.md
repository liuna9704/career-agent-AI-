# Java开发工程师岗位胜任力模型

## 能力维度：Java语言与并发能力
- 能力描述：掌握Java语言、集合、JVM和并发编程，能解释原理与适用边界。
- 评价指标：理解集合实现；掌握线程池与锁；理解JVM内存；具备故障定位经验。
- 面试验证问题：HashMap如何扩容；线程池参数如何设置；如何定位内存泄漏；锁如何选型。
- 评分标准：60-70会正确使用；71-85能解释原理并解决常见问题；86-100能结合源码和数据完成调优。

## 能力维度：后端框架与接口能力
- 能力描述：能够使用Spring Boot构建可维护服务，设计可靠接口、事务与异常处理。
- 评价指标：理解IOC/AOP；掌握事务；接口契约清晰；具备幂等与异常治理能力。
- 面试验证问题：事务为何失效；接口如何幂等；异常如何分层；自动配置如何工作。
- 评分标准：60-70能完成常规接口；71-85能处理事务和工程问题；86-100能扩展框架并治理复杂服务。

## 能力维度：数据与缓存能力
- 能力描述：掌握MySQL与Redis，能够处理索引、事务、缓存一致性和热点问题。
- 评价指标：会分析执行计划；理解事务与锁；掌握缓存策略；能够设计一致性补偿。
- 面试验证问题：慢SQL如何优化；缓存如何保证一致性；热点Key如何治理；分布式锁如何正确释放。
- 评分标准：60-70会基础使用；71-85能解决常见性能和一致性问题；86-100能治理高并发数据链路。

## 能力维度：分布式架构能力
- 能力描述：理解服务治理、一致性、消息队列、容错和容量设计。
- 评价指标：理解CAP；掌握幂等与重试；能够设计降级；具备故障模型意识。
- 面试验证问题：重复消费如何处理；服务雪崩如何避免；最终一致性如何实现；容量如何评估。
- 评分标准：60-70理解基本概念；71-85能设计常见分布式方案；86-100能在复杂故障约束下完成架构权衡。

## 能力维度：工程交付与问题解决能力
- 能力描述：具备测试、部署、可观测性、线上排障与复盘能力。
- 评价指标：测试完整；部署可回滚；日志指标有效；排障过程有证据；结果有量化。
- 面试验证问题：线上故障如何定位；灰度与回滚如何设计；哪些指标用于告警；如何复盘。
- 评分标准：60-70能完成基本交付；71-85具备稳定发布和独立排障能力；86-100能建设质量与稳定性体系。
